# united-shades

موقع تعريفي لشركة **المتحدة للمظلات — United Shades** (عربي، RTL) مبني بـ HTML/CSS/JS مع GSAP و ScrollTrigger و Lenis.

- `index.html` — نسخة (أ): هيرو "المخطط الهندسي"
- `index-classic.html` — نسخة (ب): الهيرو الغامق الكلاسيكي

للتشغيل محلياً:

```bash
python3 -m http.server 8765
```
